# AI 时代学 Excel：真实任务驱动练习仓库

> 不买书、不看几百集网课。用真实任务 + AI 答疑的方式，一步步把 Excel 练成办公技能。
> 本仓库记录每一次练习的**乱表、清洗思路和最终成果**，既是自己的学习留痕，也供同样想高效学 Excel 的人参考。

## 为什么有这个仓库

传统 Excel 教程的问题是：内容冗余、被动观看、没有反馈。这个仓库反着来——

- **任务驱动**：每个案例是一张真实办公中会出现的问题表
- **动手为主**：先自己清洗、统计，再对照参考
- **AI 辅助**：卡住了可以问 AI，学的是"解决问题"，不是"背功能"

## 学习方法（三步）

1. **拿到乱表**：打开 `乱表.xlsx`，不要看参考，先自己动手清洗
2. **对照清洗版**：做完后打开 `清洗版.xlsx`，看哪些漏了、哪些方法不同
3. **读讲解**：`讲解.md` 讲清每个脏点怎么处理、为什么这么做
